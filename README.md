# java-racingcar-precourse


## 구현할 기능 목록


### 1. 입출력 (`ConsoleView`, `InputValidator`)
- **사용자 입력**
   - 경주할 자동차 이름을 쉼표(,)로 구분하여 입력받습니다.
   - 시도할 횟수를 입력받습니다.
- **입력값 검증 (`InputValidator`)**
   - 자동차 이름은 5자 이하만 가능합니다.
   - 자동차 이름은 중복될 수 없습니다.
   - 이름이 공백이거나 쉼표로 끝나는 등 잘못된 입력을 검증합니다.
   - 시도 횟수는 양의 정수만 가능합니다.
- **결과 출력 (`ConsoleView`)**
   - 매 회차별 자동차의 전진 상태를 출력합니다.
   - 최종 우승자를 출력하며, 우승자가 여러 명일 경우 쉼표로 구분하여 모두 표시합니다.


### 2. 플레이어 (`Player`)
- 플레이어의 이름과 움직인 거리를 관리합니다.

### 3. 레이싱 핵심 로직 (`RaceService`)
- **게임 규칙 적용**
  -  레이싱 게임의 규칙을 적용합니다.
    - 무작위 값이 4 이상일 경우에만 전진
- **우승자 선정**
  - 입력받은 Player의 움직인 거리를 보고 우승자를 선정합니다.

### 4. 게임 흐름 제어 (`GameController`)
- `ConsoleView`, `InputValidator`, `RaceService`를 사용하여 전체 게임을 제어합니다.
- 사용자 입력을 받고, 유효성을 검증한 후 `RaceService`를 통해 게임을 실행합니다.
- 매 턴의 결과와 최종 우승자를 `ConsoleView`를 통해 출력하도록 제어합니다

### 5. 테스트 
- 각 클래스 별, 테스트 시나리오를 작성합니다.
