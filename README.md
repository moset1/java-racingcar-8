# java-racingcar-precourse


# 구현할 기능 목록

모든 기능은 GameController에서 실행됩니다.

1. 입출력 기능 
   - ConsoleView : 플레이어 이름, 시도 횟수 입력 기능, 콘솔에 레이싱 상태 출력 기능, 최종 우승자 출력 기능
   - InputValidator : 입력값 검증 기능
2. Player 클래스  
   - 생성 기능  
   - 현재 상태 업데이트 기능  
   - 출력 기능 
3. Game 클래스 
   - 생성 기능
   - 진행 기능
   - 결과 출력 기능
